## Pamento - Gpu For Drawing

This gpu can draw!

By engaging the gpu's screen cursor, you can draw things on-screen. Different sizes of pixels can be set, along with differing shades to use.

The screen can be cleared and it also has an erase function!

Because of the "special" nature of how I coded this, the actual program probably won't go released for a while. But a dupe is available!
