### Installation:

How to install a duplication for advanced duplicator 2:

1. Clicks on the link and download the folder
2. Find the duplicator folder along the path  
    \ SteamLibrary \ steamapps \ common \ GarrysMod \ garrysmod \ data \ advdupe2  
   (if you do not have the advdupe2 folder, then you need to download the Advanced Dublicator 2 addon)
3. go into the game and open the folder and file in the tool menu
4. Done
