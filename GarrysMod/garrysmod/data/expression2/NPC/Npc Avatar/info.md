## Description

My take on an npc avatar system. No offensive capabilities, strafing or regular-speed walking, and something of a glitchy feel when in use. In short, the work of noob, and submitted pretty much only so people can tell me what's wrong with it. Still, it's fully functional, decent with complex environments, and allows the npc to press buttons.

To aid map exploration, I also made sure it smoothly handles stargate travel. This is only relevant for cap users, but a feature nonetheless.

### To use

- Spawn the e2 on a chair
- Spawn a cam controller and wire Activated to On, and Position and Angle to the outputs of the corresponding types.
- Wire a user's input to Fire.
- Select npc with use key.
- Sit in chair.

### Controls

- **W-** forward.
- **Mouse-** turn.
- **Crouch-** first/third person
- **Primary attack-** fire use event at viewpos
- **Secondary attack-** run towards viewpos(For navigating cramped spaces)
- **Use-** When not in chair, select npc to use as avatar.
- **Reload-** Smoothly enter stargate within 200 units of eyes. You will automatically go away from gate upon exiting. Only relevant if Cap is installed.

Any mention of the term "gate" in the code is there to ensure Cap compatibility. Cap is in no way required for the chip to function.
