### RoomDetector

Next up is the RoomDetector. It detects any player that enters a room and outputs name and entity. I use it for security systems in DarkRP.  
Spawn it in a corner of the room you want it to watch and hook it up! It has variables for making it Dynamic (If you for some reason need that), ignoring the owner (on by default) and making a nice hologram box to show the detection area (Doesn't work if the room is too big)
