## [E2]Mazegame

This is an game i has been working for long, please comment if you have liked it or if you think i must change something of it.

Instructions: 1) Spawn a seat a digital screen, the e2 and a advanced pod controller
2) Link the advanced pod controller to the seat
3) Wire the e2 DS input to the digital screen and the Pod input to the advanced pod controller
4) Respawn the e2 and let the maze generate
5) Have fun
