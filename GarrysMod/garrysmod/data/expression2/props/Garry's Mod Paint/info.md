## Description

This E2 allows you to paint and *potentially* make raves!
You might be thinking "this is useless when you have the paint tool form vanilla garry's mod," but the expression can do more things than the paint tool.

### COMMANDS AND DESCRIPTION

Inspired by my chat E2 and ulx, these are the commands and descriptions for the expression 2.

```
!red [number] - set's the red of a prop to that number
!blue [number] - set's the blue of a prop to that number
!green [number] - set's the green of a prop to that number
!alpha [number] - set's the alpha of a prop to that number
!color self - colors yourself with the RGB vector currently selected
!color self rainbow - colors yourself in rainbow
!color - displays a hologram that shows your current color
!rainbow - makes a prop/entity/thing a random color constantly
!ghost - ghosts the prop you are looking at
!color sphere - colors all props around you
!remove - removes the prop you're looking at's color
!undo - undoes the very first prop you colored
!clear - clears rgb vector and removes all commands Ex. !rainbow
!record - starts the mode where you save colors
!save - saves rgb vector to array
!select - selects an array to use
reload to constantly select props and color them
use key to select props one at a time and color them
```

### INSTRUCTIONS HOW TO SAVE COLORS

```
Step 1. To begin it all, type !record to record the colors.
Step 2. Type !red, !green, and !blue just as normal.
Step 3. Type !save [number from 1-20] to save your vector.
Step 4. Type !select [umber from 1-20] to select the array you want to color with.
Step 5. Now press the Use Key or Reload on a prop to color that prop with the array.
```

Side Notes: `!clear` will not get rid of those saved arrays, removing it however will clear the array. To remove the !record just simply type `!record` again. If you plan to save to another array after already saving it once. Type `!save 0` then resume with step 2.
