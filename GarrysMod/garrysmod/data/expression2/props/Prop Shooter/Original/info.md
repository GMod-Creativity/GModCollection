## Description

Well, this E2 I made inspired by latest update on my Garry's Mod Paint E2 which could remember colors. This E2 can remember virtually infinite props that can be shot by you. This lets people who don't know how to code E2 shoot different props that would require coding knowledge before this e2...

**Note:** You have to duck and right click because some props are too big that it hits you when it spawns.
