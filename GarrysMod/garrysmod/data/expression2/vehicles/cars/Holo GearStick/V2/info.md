## Description

**UPDATE**

**Holo GearStick v2**

### Changes:

- Slight optimisation to the code, now instead of idling at 169ops, it'll spawn with ~100ops and gradually decrease at 0ops/0%, bouncing up to ~30ops when gear is changed and back down to 0ops
- Added a slight angle tilt when the stick shifts, for visual effect. (Thanks Jack37 for suggestion)
- Added the option to parent the whole thing to an external prop, just wire it directly as entity then refresh. This might seem useless now, but it'll come in handy when I'll combine multiple E2s
- More options! Now you can set the max ammount of gears between 4 and 7, might not seem a too great of a range, but Sprops shiftplates has only that set of models. If requested I'll make an extra chip for 8 gears using the hole model of the shiftplate.
- Option to chose the reverse gear. -1 most likely for E2 engines, 0 is default where Reverse is set on the last gear and 1 for ACF engines where people like to have it there than shifting trough everything.
- Height. You're now able to set the Z position of the contraption, aka at what height it sits respective to the E2/parented prop. For easier placement.
- Invisible option. Self explanatory, makes the chip transparent.

That's pretty much it, if anyone wants to make an requests and/or ask questions about something, reply below.
