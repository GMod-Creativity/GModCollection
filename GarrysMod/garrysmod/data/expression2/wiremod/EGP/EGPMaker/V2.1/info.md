A WYSIWYG editor for EGP screens, which allows those with less or no experience to build basic EGP screens easily, or those with substantial programming experience to quickly mock up boilerplate in a fashion similar to Winforms or other GUI designers.  It compiles visual representations to dense, concise EGP code.
