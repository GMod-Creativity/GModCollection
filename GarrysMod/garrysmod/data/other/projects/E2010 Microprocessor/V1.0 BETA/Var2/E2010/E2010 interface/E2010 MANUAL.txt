E2010 Programming Language for the E2010 Programming Interface

The E2010 is a Programmable microprocessor and it uses a programming language that i made, which is kind
of hard to get used to because all you do is input commands to it from the Programming Interface.
To turn on the Programming Interface, press the green power button on it and a green light will turn on.
There is a port on the programming interface and that is where you plug the E2010 chip in to input commands to it.

It is kind of hard to understand how to input a command at first, so i am going to explain it first.

the E2010 gets input from an 8 store RAM chip and cell one is the command and the cells after that one
are the arguments, which tells the E2010 how the command is going to be used.
you HAVE to specify the arguments before you set the command, like this

CELL                    |  1  |  2  |  3  |  4  |  5  |  6  |  7  |  8  |
                        -------------------------------------------------
command and arguments:     1     2     3     1    100    -     -     -
                           |     |                                   |
                        Command  -------------ARGUMENTS---------------
LANGUAGE COMMANDS AND ARGUMENTS:
-----------------------------------------
Turn ON E2010:
	command: on
Turn OFF E2010:
	command: off
   (When you turn the E2010 ON, a green light will turn on too)
--------------------------------------------------------------------------------
INPUT COMMAND: w   (for writing input to the E2010 Microprocessor)
OUTPUT 
	command : 1
	arguments:
	arg 1: (1 or 2) specifies where to output the data
				1 (output)
				2 (register)
	arg 2: (1-5) specifies which output or register to put data in
	arg 3: (1-3) specifies the source of the data being outputted
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 4: (#, 1-5, 1-5)
				if argument 3 = 1 then this argument can equal any number
				if argument 3 = 2 then this argument can equal 1-5 (registry)
				if argument 3 = 3 then this argument can equal 1-5 (input)
  EXAMPLE: Write this in the Programming Interface while you have the E2010 plugged in:
		w 1 1 5 2 3  (output value from 3rd input to 5th output)

ADD
	command: 2
	arguments:
	arg 1: (1 or 2) specifies where to output the sum
				1 (output)
				2 (register)
	arg 2: (1-5) specifies which output or register to put the sum in
	arg 3: (1-3) specifies the source of the 1st value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 4: (#, 1-5, 1-5)
				if argument 3 = 1 then this argument can equal any number
				if argument 3 = 2 then this argument can equal 1-5 (registry)
				if argument 3 = 3 then this argument can equal 1-5 (input)
	arg 5: (1-3) specifies the source of the value being added to the first value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 6: (#, 1-5, 1-5)
				if argument 5 = 1 then this argument can equal any number
				if argument 5 = 2 then this argument can equal 1-5 (registry)
				if argument 5 = 3 then this argument can equal 1-5 (input)
	EXAMPLE: Write this is the Programming interface:
			w 2 1 3 1 90 1 10   (this command outputs 100 to the 3rd output, 90 + 10 = 100)			
------------------------------------------------------------------------------------

INPUT AND OUTPUT PORTS:
	when you look on the back of the E2010 Microprocessor, you should see another E2 chip.
	That E2 chip is for the INPUT and OUTPUT. you can wire a light or anything to the output
	on the back or to the input. You could also wire a button to the input and set the on value
	to 100 and then use the output command to output 100 to an output from the input.
	INPUTS   OUTPUTS
          I1        O1
          I2        O2
          I3        O3
          I4        O4
          I5        O5
---------------------------------------------------------------------------------------
ERROR DETECTION:
	When you enter a input to the E2010, using the Programming Interface, the E2010 will make sure that 
	you entered the arguments correctly.
	If you enter an argument of a command incorrectly, the E2010 will have a flashing red light.
	When the error occurs, an Error Code is created and sent to another RAM chip.
	The first cell in the Error Code RAM chip referes to what command the error occured in and the
	cells after the first tells what kind of error occured in the command that was ran.
	There are several error codes and dont worry about having to memorize all of these error codes.
	If you do get an error, just view the Error Code list below:
ERROR CODES:

1: (output related error)
	1 1	(1st argument is not equal to 1 or 2)
	1 2 (2nd argument is not within the range of 1-5)
	1 3 (3rd argument is not within the range of 1-3)
	1 4 (4th argument is not in relation to argument 3)


2: (addition command errors)
	2 1 (1st argument does not equal 1 or 2)
	2 2 (2nd argument is not within the range of 1-5)
	2 3 (3rd argument is not within the range of 1-3)
	2 4 (4th argument is not in relation to argument 3)
	2 5 (5th argument is not within the range of 1-3)
	2 6 (6th argument is not in relation to argument 5)
