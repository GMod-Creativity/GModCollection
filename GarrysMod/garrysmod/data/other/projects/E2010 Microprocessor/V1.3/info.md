## E2 Microprocessor (E2010)

**E2010 Microprocessor Project**
  
Hi Everyone, This thread is about my new E2010 Microprocessor that i am working on.
Here are a couple pictures of what it looks like:
  
The E2010 is a Wire Microprocessor that allows numerical input with the Programming Interface. It runs off of an Expression 2 chip.
I am working on the E2010 a little at a time and there is already 2 commands that the E2010 can recognize.
The 2 commands are the OUTPUT and ADDITION commands.
Just those 2 commands does a lot, so when i get more commands in, its gonna be able to do even more.
Once i am finished adding all of the main commands, i am going to make it have program runtime where you can
write a program to the CPU program memory and actually run commands and loops. Its going to be awesome.
