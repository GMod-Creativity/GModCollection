E2010 Microprocessor (Release 1.4)
	UPDATES:
		1. Subtraction command added
		2. Multiplication command added
		3. Division command added
		4. fixed error codes on addition command

The E2010 is a Wire Microprocessor that allows numerical command input to run functions and process data.
The E2010 runs processes after it reads a command input with the arguments. The arguments tell the E2010 how
a command is going to be ran.
The Programming Interface is what you use to input commands to the E2010, You plug the E2010 into the socket on the
Programming interface.

                        -------------------------------------------------
command and arguments:     1     2     3     1    100    -     -     -
                           |     |                                   |
                        Command  -------------ARGUMENTS---------------
LANGUAGE COMMANDS AND ARGUMENTS:
-----------------------------------------
Turn ON E2010:
	command: on
Turn OFF E2010:
	command: off
   (When you turn the E2010 ON, a green light will turn on too)


INPUT AND OUTPUT PORTS:
	The input and output ports are on the E2 chip on the E2010 Microprocessor.
	INPUTS   OUTPUTS
          I1        O1
          I2        O2
          I3        O3
          I4        O4
          I5        O5
--------------------------------------------------------------------------------
INPUT COMMAND: w   (for writing input to the E2010 Microprocessor)
OUTPUT 
	command : 1
	arguments:
	arg 1: (1 or 2) specifies where to output the data
				1 (output)
				2 (register)
	arg 2: (1-5) specifies which output or register to put data in
	arg 3: (1-3) specifies the source of the data being outputted
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 4: (#, 1-5, 1-5)
				if argument 3 = 1 then this argument can equal any number
				if argument 3 = 2 then this argument can equal 1-5 (registry)
				if argument 3 = 3 then this argument can equal 1-5 (input)
  EXAMPLE: Write this in the Programming Interface while you have the E2010 plugged in:
		w 1 1 5 2 3  (output value from 3rd input to 5th output)

ADD
	command: 2
	arguments:
	arg 1: (1 or 2) specifies where to output the sum
				1 (output)
				2 (register)
	arg 2: (1-5) specifies which output or register to put the sum in
	arg 3: (1-3) specifies the source of the 1st value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 4: (#, 1-5, 1-5)
				if argument 3 = 1 then this argument can equal any number
				if argument 3 = 2 then this argument can equal 1-5 (registry)
				if argument 3 = 3 then this argument can equal 1-5 (input)
	arg 5: (1-3) specifies the source of the value being added to the first value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 6: (#, 1-5, 1-5)
				if argument 5 = 1 then this argument can equal any number
				if argument 5 = 2 then this argument can equal 1-5 (registry)
				if argument 5 = 3 then this argument can equal 1-5 (input)
	EXAMPLE: Write this is the Programming interface:
			w 2 1 3 1 90 1 10   (this command outputs 100 to the 3rd output, 90 + 10 = 100)

SUBTRACT
	command: 3
	arguments:
	arg 1: (1 or 2) specifies where to output the outcome
				1 (output)
				2 (register)
	arg 2: (1-5) specifies which output or register to put the sum in
	arg 3: (1-3) specifies the source of the 1st value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 4: (#, 1-5, 1-5)
				if argument 3 = 1 then this argument can equal any number
				if argument 3 = 2 then this argument can equal 1-5 (registry)
				if argument 3 = 3 then this argument can equal 1-5 (input)
	arg 5: (1-3) specifies the source of the value subtracting from the first value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 6: (#, 1-5, 1-5)
				if argument 5 = 1 then this argument can equal any number
				if argument 5 = 2 then this argument can equal 1-5 (registry)
				if argument 5 = 3 then this argument can equal 1-5 (input)
	EXAMPLE: Write this is the Programming interface:
			w 3 1 1 1 100 1 50   (This command subtracts 50 from 100 and outputs it to output port 1)

MULTIPLY
	command: 4
	arguments:
	arg 1: (1 or 2) specifies where to output the sum
				1 (output)
				2 (register)
	arg 2: (1-5) specifies which output or register to put the product in
	arg 3: (1-3) specifies the source of the 1st value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 4: (#, 1-5, 1-5)
				if argument 3 = 1 then this argument can equal any number
				if argument 3 = 2 then this argument can equal 1-5 (registry)
				if argument 3 = 3 then this argument can equal 1-5 (input)
	arg 5: (1-3) specifies the source of the value multiplying the first value
				1 (any specified value)
				2 (import value from input)
				3 (import value from register)
	arg 6: (#, 1-5, 1-5)
				if argument 5 = 1 then this argument can equal any number
				if argument 5 = 2 then this argument can equal 1-5 (registry)
				if argument 5 = 3 then this argument can equal 1-5 (input)
	EXAMPLE: Write this is the Programming interface:
			w 4 1 1 2 4 1 10   (This command multiplies the value of input 4 by 10 and the product is sent to output port 1)

ERROR DETECTION:
	When you enter an input to the E2010 with the interface, the E2010 will check if the inputted command
	and arguments are correct. If you input invalid command and arguments, the E2010 will generate the error
	code and the programming interface will read the error code and print out a message saying that there
	was an error and display the error code.
ERROR CODES:

1: (output related error)
	1 1	(1st argument is not equal to 1 or 2)
	1 2 (2nd argument is not within the range of 1-5)
	1 3 (3rd argument is not within the range of 1-3)
	1 4 (4th argument is not in relation to argument 3)


2: (addition command errors)
	2 1 (1st argument does not equal 1 or 2)
	2 2 (2nd argument is not within the range of 1-5)
	2 3 (3rd argument is not within the range of 1-3)
	2 4 (4th argument is not in relation to argument 3)
	2 5 (5th argument is not within the range of 1-3)
	2 6 (6th argument is not in relation to argument 5)

3: (subtraction command errors)
	3 1 (1st argument does not equal 1 or 2)
	3 2 (2nd argument is not within the range of 1-5)
	3 3 (3rd argument is not within the range of 1-3)
	3 4 (4th argument is not in relation to argument 3)
	3 5 (5th argument is not within the range of 1-3)
	3 6 (6th argument is not in relation to argument 5)

4: (multiplication command errors)
	4 1 (1st argument does not equal 1 or 2)
	4 2 (2nd argument is not within the range of 1-5)
	4 3 (3rd argument is not within the range of 1-3)
	4 4 (4th argument is not in relation to argument 3)
	4 5 (5th argument is not within the range of 1-3)
	4 6 (6th argument is not in relation to argument 5)

5: (division command errors)
	5 1 (1st argument does not equal 1 or 2)
	5 2 (2nd argument is not within the range of 1-5)
	5 3 (3rd argument is not within the range of 1-3)
	5 4 (4th argument is not in relation to argument 3)
	5 5 (5th argument is not within the range of 1-3)
	5 6 (6th argument is not in relation to argument 5)
